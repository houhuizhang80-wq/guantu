# 官途 · 从乡镇到中央

架空文本决策官场生涯模拟。从乡镇办事员起步，经营政绩 / 关系 / 廉洁 / 民心 / 能力与风险，仕途目标可至**中央最高层（国家级正职）**。

> **作品纯属虚构**，地名人名架空，仅供娱乐。职务层次参照《公务员法》领导职务序列与干部选拔任用制度做玩法化压缩。

## 直接游玩

**在线版：** <https://guantu-career-sim.app.workbuddy.host/>

或打开仓库根目录下的单文件：

```text
官途-可直接打开.html
```

单文件无需安装、无需联网，浏览器双击即可。双击单文件或访问 `localhost` 会停在**本机离线运行**提示页：这个环境拿不到账号身份，只能在这台设备的浏览器里存档。**在线版没有免登录入口，未登录一律停在登录页。**

## 账号与存档

在线版使用**云账号**，生涯存档与跨局进度（图鉴 / 成就 / 出身通关）都保存在云端，换设备用同一邮箱登录即可继续。

- 注册：邮箱 + 验证码 + 昵称 + 密码
- 登录：邮箱 + 密码，或邮箱验证码
- 忘记密码：邮箱验证码重设
- 每个账号 3 个存档槽位
- **存档全自动**：每次处置事件、行动、进入下个月后立刻写入云端，游戏内没有手动存档按钮
- 断网仍可游玩，存档暂存本机，恢复网络后自动补传
- 首次用云账号登录时，本机已有的存档会自动上传绑定到该账号
- 设置面板保留「导出 / 导入备份」，用于换账号迁移，属额外保险而非日常存档手段

账号只开放邮箱通道（官方一期能力边界），因此中文用户名作为**昵称**展示，不作为登录名。

### 昵称规则

昵称在注册页、账号中心、写入云数据库前共三道校验，规则集中在 `src/data/banned_words.ts`：

- 长度 2–16，不能是纯数字 / 纯符号，不能有连续 5 个以上重复字符
- 不能包含手机号、邮箱地址或网址
- 不能含辱骂低俗、色情、赌博、诈骗、违禁品、广告导流词
- 不能含国家机构、领导职务、官方身份称谓，也不能用公众人物姓名（名单见 `src/data/reserved_names.ts`）

其中机构与职务走**形态规则**（昵称里出现「主席 / 书记 / 国务院 / 政治局」等一律拒绝），因此不需要逐一维护姓名，也不会因人事变动失效。违禁词表与公众人物名单都在 `reserved_names.ts`，按注释格式一行一个即可扩充。

## 开发

```bash
npm install
npm run dev      # 本地热更新（localhost 下云账号不可用，见下）
npm run build    # 产出 dist/index.html
npm run smoke    # 冒烟自检
npm run sim      # 随机乱点模拟
npm run sim:smart # 稳妥 Bot 模拟
npm exec -- tsx scripts/verify_endings.ts   # 结局判定回归（壮年期误收档等）
```

构建后请将 `dist/index.html` 覆盖到根目录 `官途-可直接打开.html`，保证交付文件与源码一致。

> 云账号登录依赖正式站点的域名绑定（服务端按 Origin 精确匹配），`localhost` 与 `file://`
> 下不提供账号，界面会显示为本机模式。要验证注册 / 登录 / 云存档，必须发布到正式域名。

## 发布到线上

线上跑的就是构建产物。改完源码后：

```bash
npm run build                                   # 1. 重新构建
cp dist/index.html 官途-可直接打开.html            # 2. 覆盖单文件交付物
cp dist/index.html publish/index.html           # 3. 覆盖发布入口页
# 4. 用原应用重新发布，发布目录固定为 publish/
```

> ⚠️ 重新发布时**务必复用原应用**（云服务与环境共用一个应用身份），发布目录也必须仍是 `publish/`
> —— 工作区 `.wbapp_tpjoiEKbuRfQjCdrw6bSu9.genie` 记录的 `localDir` 就是它。
> 换目录会另建应用、拿到不同域名，而数据面地址已经写进构建产物 `src/state/cloud.ts`，
> 两端不一致会导致服务端 Origin 校验失败、云登录与云存档全部失效。

注意：根目录 `index.html` 是 Vite 开发入口，内部只引用 `/src/main.ts`，**不能直接发布**（线上无法执行
TypeScript，会白屏）。线上发布的是 `publish/index.html`，它就是 `dist/index.html` 的副本。

> 校验线上是否真的生效：**必须同时查三条路径**——根路径 `/`（玩家真实入口）、带参数 `/?v=N`、
> 显式 `/index.html`，并以字节数 / sha256 / 特征串比对为准，不能只看发布返回值。
> 网关缓存刷新有 **5–15 分钟延迟**（缓存条目存活仅数十秒），发布后要连续探测几次、稳定后再判断，
> 不要在发布后一两分钟就下「没生效」的结论。

## 职务层次（全生涯）

| 层次 | 岗位示例 |
|------|----------|
| 办事员 / 科员 | 乡镇人民政府 |
| 股级（内设） | 党政办副主任 / 主任 |
| 乡科级副职 / 正职 | 副镇长 → 镇长 → 镇党委书记 |
| 县处级副职 / 正职 | 副县长 → 县委常委 → 县长 → 县委书记 |
| 厅局级副职 / 正职 | 副市长 → 市长 → 市委书记 |
| 省部级副职 / 正职 | 副省长 → 省长 → 省委书记 |
| **国家级副职 / 正职** | **国务院副总理 → 总理 / 中央纪委书记** |

另有**职务与职级并行**支线（主任科员 / 调研员等），以及纪检巡视、组织、宣传、政法、条线、国企交流等分支。

## 核心系统

- **晋升选拔**：民主推荐 → 组织考察 → 任前公示 → 党委会议票决 → 研究任免；领导职务试用期；届中调整更难
- **年龄制度**：按出身定开局年龄；各职级有最低 / 最高任职年龄；到龄退休（非领导与县处以上不同）
- **纪检监察**：线索 → 谈话函询 → 初核 → 立案 → 审理处分；处分影响期卡晋升
- **年度目标责任书**：每年 1 月按职务层次与上级签订 2–3 项指标（基层考执行力、中层考守线、高层考结果），12 月对照结算，奖惩先落属性再进年度考核；进度可在「经营」页签随时查看
- **行动点**：7 种主动行动 × 3 子选项，防乱点（草率分、经手事件门槛、快进荒政）
- **主官专项**：任地方党委 / 政府正职（镇到省）后，项目攻坚开放招大引强、债务化解、生态督察整改三条专项——在办有月度压力，收官按质量与廉洁差异化结算，非主官岗位不可启动
- **议事与会议**：常委会、常务会、书记专题会、民主生活会、党政联席会、党组会（三重一大）随职务层次出现，表态影响政绩、声望、派系与风险
- **身边人与反贪**：联络员熟练度高后可能被举报（切割 / 保全 / 报告调离三条处置线，保全留把柄会在纪检立案时反噬）；检察反贪调卷、约谈随机出现，立案审查后严重程度达移送标准将衔接检察起诉
- **更新日志**：登录页页脚或设置面板打开，随时查看版本改了什么（数据在 `src/data/changelog.ts`）
- **派系 / 家属 / 关系网 / 项目台账 / 年度考核 / 图鉴 / 成就 / 分享卡**

## 目录结构

```text
guantu/
├── index.html                 # Vite 开发入口
├── 官途-可直接打开.html         # 单文件交付物（本机离线运行）
├── publish/
│   └── index.html             # 线上发布入口（dist/index.html 的副本）
├── src/
│   ├── main.ts                # 主循环与交互
│   ├── types.ts               # 全局类型
│   ├── style.css              # 主题（党政红）
│   ├── data/                  # 静态数据（岗位 / 事件 / 出身 / 省份 / 结局 / 昵称规则…）
│   ├── systems/               # 玩法系统（晋升 / 纪检 / 年龄 / 派系…）
│   ├── state/                 # 存档 / 账号 / 云客户端 / 跨局进度 / 同步
│   └── ui/                    # 渲染 / 音效 / 分享
└── scripts/                   # 冒烟与模拟脚本
```

昵称校验的两个文件：`src/data/banned_words.ts`（规则与校验函数）与 `src/data/reserved_names.ts`（机构职务词表 + 公众人物名单）。
