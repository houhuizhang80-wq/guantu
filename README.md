架空文本决策官场生涯模拟。从乡镇办事员起步，经营政绩 / 关系 / 廉洁 / 民心 / 能力与风险，仕途目标可至**中央最高层（国家级正职）**。

## 存档

- **6 个存档槽位**，操作后自动写入（离线写本机；启用云端账号时同步到云端）
- 断网仍可游玩；恢复网络后自动补传（仅云端账号模式）
- 设置面板「导出 / 导入备份」：导出为 **AES-GCM 加密** `.guantu`（非明文），导入时需密码；也兼容旧版明文 / 旧混淆文件
- 加密包一并带上图鉴 / 出身通关，导入后自动合并

云端账号（邮箱注册 / 登录、跨设备同步）依赖服务端域名绑定；GitHub Pages 与本地单文件为离线模式，无账号入口。

## 开发

```bash
npm install
npm run dev      # 本地热更新（localhost 下云账号不可用，见下）
npm run build    # 产出 dist/index.html
npm run smoke    # 冒烟自检
npm run sim      # 随机乱点模拟
npm run sim:smart # 稳妥 Bot 模拟
npm exec -- tsx scripts/verify_endings.ts   # 结局判定回归（壮年期误收档等）
```

构建后请将 `dist/index.html` 覆盖到根目录 `官途-可直接打开.html`，保证交付文件与源码一致。

> 云账号登录依赖正式站点的域名绑定（服务端按 Origin 精确匹配），`localhost` 与 `file://`
> 下不提供账号，界面会显示为本机模式。要验证注册 / 登录 / 云存档，必须发布到正式域名。

## 发布到线上

公开试玩走 **GitHub Pages**（`docs/` 目录）：

```bash
npm run build                                   # 1. 重新构建
cp dist/index.html 官途-可直接打开.html            # 2. 覆盖单文件交付物
cp dist/index.html docs/index.html              # 3. 覆盖 Pages 入口
cp dist/index.html publish/index.html           # 4. 若仍维护旧发布目录
git add docs/index.html && git commit && git push
```

Pages 约几分钟后自动生效：https://houhuizhang80-wq.github.io/guantu/

注意：根目录 `index.html` 是 Vite 开发入口，内部只引用 `/src/main.ts`，**不能直接发布**（线上无法执行 TypeScript，会白屏）。线上发布的是构建后的单文件（`docs/index.html`）。

## 核心系统

- **晋升选拔**：民主推荐 → 组织考察 → 任前公示 → 党委会议票决 → 研究任免；失败给出分环节复盘；领导职务试用期；届中调整更难
- **年龄与任期**：按出身定开局年龄；各职级年龄窗与任职月数（多数 14–24 月）；到龄退休
- **纪检监察**：线索 → 谈话函询 → 初核 → 立案 → 审理处分；处分影响期卡晋升
- **政策试点**：县处起选定一条线做 3–4 个月，结项质量进属性，并写入本年考核加分
- **派系交办**：站队后可能收到交办；办成涨声望、常伤廉洁；办砸则对家下月报复
- **年度目标责任书**：每年 1 月签订 2–3 项指标，12 月对照结算
- **行动点**：7 种主动行动 × 3 子选项，防乱点（草率分、经手事件门槛、快进荒政）
- **议事与会议 / 身边人与反贪 / 主官专项 / 图鉴解锁提示**
- **存档**：6 槽位自动存档；导出 `.guantu` 为 AES-GCM 加密备份（非明文）；玩家交流 QQ 群 1107570877
- **事件降重**：冷却窗口拉长 + 见得越多权重越低 + 未见优先

## 目录结构

```text
guantu/
├── index.html                 # Vite 开发入口
├── 官途-可直接打开.html         # 单文件交付物（本机离线运行）
├── publish/
│   └── index.html             # 线上发布入口（dist/index.html 的副本）
├── src/
│   ├── main.ts                # 主循环与交互
│   ├── types.ts               # 全局类型
│   ├── style.css              # 主题（党政红）
│   ├── data/                  # 静态数据（岗位 / 事件 / 出身 / 省份 / 结局 / 昵称规则…）
│   ├── systems/               # 玩法系统（晋升 / 纪检 / 年龄 / 派系…）
│   ├── state/                 # 存档 / 账号 / 云客户端 / 跨局进度 / 同步
│   └── ui/                    # 渲染 / 音效 / 分享
└── scripts/                   # 冒烟与模拟脚本
```

昵称校验的两个文件：`src/data/banned_words.ts`（规则与校验函数）与 `src/data/reserved_names.ts`（机构职务词表 + 公众人物名单）。
